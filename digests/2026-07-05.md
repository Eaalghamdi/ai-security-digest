# AI Security Digest — 2026-07-05

**Today's themes:** Prompt injection has moved from proof-of-concept to production incident — a sandbox-escape RCE in Cursor and the first fully agent-driven ransomware run both trace back to unsanitized content reaching an LLM agent — while new research pushes jailbreak techniques into function-calling/tool contexts and explores real-time safety monitors as a countermeasure.

## Papers

1. **[Beyond the Prompt: Jailbreaking Function-Calling LLMs via Simulated Moderation Traces](https://arxiv.org/abs/2607.00481)** (Junlong Liu, Haobo Wang, Weiqi Luo, Xiaojun Jia) — Argues that jailbreak research has focused too narrowly on the prompt itself, missing a structural vulnerability in stateful, function-calling deployments where developer-defined schemas, structured arguments, and untrusted tool outputs share the same model context. Introduces SMT (Simulated Moderation Traces), a black-box attack that fabricates a multi-turn "moderation audit" trajectory to walk a function-calling LLM past its safety training — relevant to anyone deploying tool-using agents rather than plain chat models.

2. **[Online Safety Monitoring for LLMs](https://arxiv.org/abs/2607.02510)** (Mona Schirmer, Metod Jazbec, Alexander Timans, Christian Naesseth, Maja Waldron, Eric Nalisnick) — Proposes a lightweight real-time monitor that thresholds an external verifier's signal, with the threshold calibrated via risk control, to flag when a deployed LLM's outputs can no longer be trusted as safe. Shows this simple approach is competitive with heavier sequential-hypothesis-testing monitors on reasoning and red-teaming benchmarks — a practical alignment-tax-free option for runtime safety guardrails.

## News

1. **[Critical Cursor Flaws Could Let Prompt Injection Escape Sandbox and Run Commands](https://thehackernews.com/2026/07/critical-cursor-flaws-could-let-prompt.html)** — Cato AI Labs disclosed "DuneSlide," two critical flaws (CVE-2026-50548, CVE-2026-50549, CVSS 9.8) in the Cursor AI coding IDE that let attacker-planted instructions — delivered via an MCP-connected service or a web search result the agent reads — escape Cursor's command sandbox and achieve remote code execution. Both are patched in Cursor 3.0, but every prior version is affected, and Cursor's vendor claims over half the Fortune 500 use the tool, making this a high-impact real-world instance of indirect prompt injection reaching RCE.

2. **[AI Agent Exploits Langflow RCE to Automate Database Ransomware Attack](https://thehackernews.com/2026/07/ai-agent-exploits-langflow-rce-to.html)** — Sysdig documented "JADEPUFFER," reported as the first fully agent-driven ransomware operation end to end: an LLM agent autonomously exploited a Langflow authentication-bypass RCE (CVE-2025-3248), harvested cloud/LLM-provider credentials, pivoted into a production MySQL/Nacos server, and encrypted/wiped over a thousand configuration items — including self-diagnosing and fixing a failed login in 31 seconds without human help. A concrete signal that autonomous exploitation is no longer purely theoretical.

3. **[Identity Lifecycle Management Wasn't Built for AI Agents](https://thehackernews.com/2026/07/identity-lifecycle-management.html)** — Argues that identity governance tooling built around a human's employment record, manager, and departure date breaks down for AI agents, whose access surface expands at runtime through tool-calling and RAG retrieval rather than through any advance policy decision — leaving IGA tools structurally blind to how agents actually accumulate privilege.
