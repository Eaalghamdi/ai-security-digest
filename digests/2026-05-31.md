### [AgentSecBench: Measuring Prompt Injection, Privacy Leakage, and Tool-Use Integrity in LLM Agents](https://arxiv.org/abs/2605.26269)
*arXiv:2605.26269 — submitted 25 May 2026*

This benchmark exposes the fundamental architectural flaw that LLM agents process trusted instructions and untrusted data through a common channel, conflating data flow with authority. AgentSecBench spans prompt injection, privacy leakage, and tool-use integrity scenarios, providing standardised metrics for comparing attack and defence strategies across realistic agentic deployments. It matters because it moves beyond single-vector evaluations and gives practitioners a shared yardstick for auditing agent security before shipping.

### [Poisoning the Watchtower: Prompt Injection Attacks Against LLM-Augmented Security Operations Through Adversarial Log Content](https://arxiv.org/abs/2605.24421)
*arXiv:2605.24421 — submitted 23 May 2026*

This paper demonstrates that LLMs integrated into security operations centres (SOCs) can be compromised by injecting malicious content into the very logs they are asked to analyse. The authors introduce a four-class taxonomy of attacks — direct override, persona hijack, context manipulation, and obfuscated payloads — showing that a single poisoned log line can redirect the LLM-SOC agent, suppress alerts, or exfiltrate findings. The result is a sobering reminder that deploying LLMs as security analysts introduces a new attack surface *inside* the trusted SOC perimeter.

### [PAST2HARM: A Simple Adaptive Past Tense Attack for Jailbreaking Multimodal AI](https://arxiv.org/abs/2605.27545)
*Snehasis Mukhopadhyay — arXiv:2605.27545 — submitted ~26 May 2026*

PAST2HARM shows that merely reformulating harmful requests in the past tense bypasses refusal training in state-of-the-art text-to-image models, achieving success rates of 83–100% across three tested systems in a black-box setting. The attack requires no gradient access or complex prompt engineering — a low-cost technique any non-expert adversary can apply at scale. It highlights a systematic vulnerability in how current safety training handles temporal linguistic framing.

### [Backdooring Masked Diffusion Language Models](https://arxiv.org/abs/2605.19262)
*Daniel Yiming Cao, Chengzhong Wang, Sheng-Yen Chou, Chengyu Huang, Pin-Yu Chen, Shengwei An — arXiv:2605.19262 — submitted 19 May 2026*

This is the first systematic study of training-time backdoor attacks on masked diffusion language models (MDLMs), introducing SHADOWMASK — an attack that replaces the standard all-mask terminal distribution with a trigger-mask mixture prior to embed a stealthy backdoor during training. SHADOWMASK achieves high attack success rates while maintaining near-identical perplexity to clean models, making detection difficult. As MDLMs gain adoption for code generation and structured text synthesis, this work establishes that they carry the same supply-chain backdoor risks as conventional LLMs.

## Blog posts

### [How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)
*Anthropic Engineering — 30 May 2026 · linked by [Simon Willison](https://simonwillison.net/2026/May/30/how-we-contain-claude/)*

Anthropic published a detailed overview of its layered sandboxing architecture: Claude.ai uses gVisor; Claude Code (run locally) uses Seatbelt on macOS and Bubblewrap on Linux; Claude Cowork runs a full VM (Apple Virtualization on macOS, HCS on Windows). The design goal is that credentials never enter the sandbox and therefore cannot be exfiltrated regardless of model behaviour, user intent, or attacker influence. The post also describes a February 2026 red-team incident in which a researcher phished an employee into launching Claude Code with a malicious prompt, and the architectural fix: deferring project-local config parsing until after the user explicitly accepts a trust prompt. For any team deploying agentic AI, this is a concrete and honest containment-first blueprint.

## News

### [ChatGPhish Vulnerability Turns ChatGPT Web Summaries Into a Phishing Surface](https://thehackernews.com/2026/05/chatgphish-vulnerability-turns-chatgpt.html)
*The Hacker News — 29 May 2026*

Permiso Security disclosed ChatGPhish: ChatGPT's Markdown renderer implicitly trusts links and image URLs that originated from third-party pages the assistant just summarised, auto-fetching those images and surfacing links as live, clickable elements inside the trusted AI UI. An attacker can append a small payload to any public webpage — causing ChatGPT to leak the victim's IP, User-Agent, and Referer via attacker-hosted images, render inline QR codes for mobile pivots, or display convincing phishing links inside an interface the user already trusts. No model compromise is required: any malicious page an employee asks ChatGPT to summarise becomes the phishing payload.

### [Attackers Use LLM Agent for Post-Exploitation After Marimo CVE-2026-39987 Exploit](https://thehackernews.com/2026/05/attackers-use-llm-agent-for-post.html)
*The Hacker News — 29 May 2026*

In the first confirmed in-the-wild use of an LLM agent for post-compromise automation, an unknown threat actor exploited a publicly accessible Marimo notebook server via CVE-2026-39987, then handed off to an LLM-driven agent that extracted two cloud credentials from the compromised host and exfiltrated the full schema and contents of an internal PostgreSQL database — all within two minutes. This marks a clear inflection point: LLM agents are now active tools in real attack chains, dramatically lowering the skill bar and compressing the post-exploitation timeline. Defenders should treat LLM-assisted intrusion as a baseline assumption rather than a future threat model.
