# AI Security Digest — 2026-07-26

**Today's themes:** Both confirmed stories this cycle show attackers weaponizing legitimate agentic-AI features against their operators — a single crafted link that forges a persistent, over-privileged ChatGPT agent inside a victim's workspace, and a real intrusion where an open-source agent running in unattended "YOLO mode" automated post-exploitation at a national finance ministry. ## News

### [ChatGPT AgentForger Flaw Could Deploy Rogue Workspace Agents via a Phishing Link](https://thehackernews.com/2026/07/chatgpt-agentforger-flaw-could-deploy.html)
*The Hacker News — 24 July 2026, reporting research by Zenity Labs*

Zenity Labs disclosed "AgentForger": ChatGPT's Workspace Agent Builder executes an `initial_assistant_prompt` URL parameter automatically on page load instead of just populating the prompt box, so a single link of the form `chatgpt[.]com/agents/studio/new?template_name=...&initial_assistant_prompt=...` can silently build and launch a malicious agent the moment a victim clicks it. The forged agent inherits every enterprise integration the employee had already authorized — email, calendar, cloud storage, Slack, Teams — letting it exfiltrate data, harvest credentials/MFA tokens, and impersonate the employee indefinitely. OpenAI patched the flaw (fixed as of June 8, 2026) after responsible disclosure; it's a clean example of how a UX convenience (URL-driven agent deep-linking) becomes a one-click privilege-escalation path once agents hold standing access to real tools.

### [Hacker Runs Hermes AI Agent Unattended for Post-Exploitation at Thai Finance Ministry](https://thehackernews.com/2026/07/hacker-runs-hermes-ai-agent-unattended.html)
*The Hacker News — 24 July 2026, based on Hunt.io research*

Researchers at Hunt.io recovered three open directories (585 files, ~470MB) from a Hong Kong-hosted server used in a live intrusion against Thailand's Ministry of Finance, showing an operator running the open-source Hermes agent in "YOLO mode" — which strips the approval prompts normally required before executing dangerous commands. Logs show Hermes autonomously driving privilege escalation, kernel vulnerability scanning, service enumeration, and file-system traversal, alongside a previously undocumented Go-based implant the operator named "Hades." It's a concrete data point for a trend the sector has been anticipating rather than observing: real adversaries running agentic tooling unattended, end-to-end, inside a live post-exploitation chain.
