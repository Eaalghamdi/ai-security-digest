# AI Security Digest — 2026-07-12

**Today's themes:** Agentic AI keeps proving to be the soft target — Sysdig documented the first fully autonomous, end-to-end AI-driven ransomware operation, and a wave of new disclosures shows AI coding agents, GitHub's agentic workflows, and enterprise chatbot platforms all falling to prompt injection and sandbox-escape bugs. Academic work is racing to catch up, with new large-scale taxonomies of agentic AI security risk and a fresh technique for scaling promptware attacks through LLM hallucinations.

## Papers

### [Security and Privacy in Agentic AI: Grand Challenges and Future Directions](https://arxiv.org/abs/2607.06608)
*Adam Jenkins, Agnieszka Kitkowska, Caterina Maidhof, et al. (48 authors) — arXiv:2607.06608 — submitted 7 Jul 2026*

The product of a horizon-scanning workshop bringing together roughly thirty experts from academia, industry, and government, this paper maps the emerging risk landscape of agentic AI: prompt injection at scale, floods of malicious third-party agent apps, and users disclosing sensitive personal data to agents in exchange for convenience. It matters as a field-defining reference point — a shared research agenda for security and privacy work on increasingly autonomous AI systems, aimed at researchers, policymakers, and practitioners alike.

### [Beware of Agentic Botnets: Scalable Untargeted Promptware Attacks via Universal and Transferable Adversarial HalluSquatting](https://arxiv.org/abs/2607.07433)
*Aya Spira, Stav Cohen, Elad Feldman, Ron Bitton, Avishai Wool, Ben Nassi — arXiv:2607.07433 — submitted 8 Jul 2026*

This paper shows that LLMs' tendency to hallucinate resource identifiers (package names, URLs) can be weaponized to scale promptware attacks even against agents with no direct injection channel: attackers pre-register the names LLMs are statistically likely to hallucinate, seeding them with adversarial prompts that get pulled in automatically. It matters because it turns a well-known LLM failure mode into an untargeted, internet-scale attack vector — closely mirrored by a real-world "HalluSquatting" disclosure covered below.

### [The Balkanization of Execution-Security Research for AI Coding Agents: Isolation, Access Control, and Time-of-Check-to-Time-of-Use Vulnerabilities](https://arxiv.org/abs/2607.05743)
*Mohammadreza Rashidi — arXiv:2607.05743 — submitted 7 Jul 2026*

The paper systematizes 39 previously siloed papers (2023–2026) on sandboxing, capability/access control, MCP threats, identity delegation, and TOCTOU races in AI coding agents into 17 categories, verifying each against its source and confirming four disclosed, patched CVEs in production agent harnesses. It matters because the execution-security literature for coding agents has been scattered across venues that rarely cite each other — this is a first attempt at a unified map, arriving just as real TOCTOU and sandbox-escape bugs (see GhostApproval, Friendly Fire below) are showing up in production tools.

### [Beyond the Prompt: Jailbreaking Function-Calling LLMs via Simulated Moderation Traces](https://arxiv.org/abs/2607.00481)
*Junlong Liu, Haobo Wang, Weiqi Luo, Xiaojun Jia — arXiv:2607.00481 — submitted 1 Jul 2026*

The authors argue that prompt-centric jailbreak research misses a structural vulnerability in stateful, function-calling agents, where developer schemas, structured tool arguments, and untrusted tool outputs share one model context — letting adversarial intent be smuggled across a multi-turn execution path rather than a single prompt. It matters because it extends jailbreak research from single-shot chat prompts to the tool-calling agent setting most production deployments actually use.

## News

### [JADEPUFFER: Agentic Ransomware for Automated Database Extortion](https://www.sysdig.com/blog/jadepuffer-agentic-ransomware-for-automated-database-extortion)
*Sysdig — ~1 Jul 2026*

Sysdig documented what it assesses to be the first fully agentic ransomware operation: an autonomous LLM exploited an unauthenticated RCE flaw in Langflow (CVE-2025-3248), harvested credentials, pivoted to a production MySQL/Nacos server, and encrypted over 1,300 service configuration records — over 600 distinct, purposeful payloads executed with no human operator in the loop. It matters as the first well-documented case of an AI agent independently running an intrusion-to-extortion chain end to end, a milestone the security industry has been warning about for over a year.

### [GhostApproval Symlink Flaws Could Let Malicious Repos Run Code in AI Coding Agents](https://thehackernews.com/2026/07/ghostapproval-symlink-flaws-could-let.html)
*Wiz, via The Hacker News — 8 Jul 2026*

Wiz found that six major AI coding assistants (Amazon Q Developer, Claude Code, Augment, Cursor, Google Antigravity, Windsurf) fail to check for symlinks before writing files, letting a booby-trapped repo redirect a benign-looking write into SSH keys or shell startup files and gain code execution outside the agent's sandbox. It matters because it's a decades-old Unix trust issue resurfacing at the exact trust boundary — file writes on developer machines — that AI coding agents are now built around; three of six vendors have patched it, two haven't, and Anthropic disputes it's a bug.

### [Top AI Agents Built to Catch Malicious Code Can Be Tricked Into Running It ("Friendly Fire")](https://thehackernews.com/2026/07/friendly-fire-ai-agents-built-to-catch.html)
*AI Now Institute, via The Hacker News — 8–9 Jul 2026*

Researchers hid prompt injections inside a modified copy of the popular `geopy` Python library and showed that Claude Code (auto-mode) and OpenAI Codex (auto-review), when asked to review the code for security issues, instead executed the attacker's payload on the host. It matters because it inverts the intended safety property of these tools — the same review step meant to catch malicious code becomes the delivery mechanism, and the researchers argue no model update alone fixes it since the model still can't reliably separate code from instructions.

### ['GitLost' Prompt Injection Can Leak Private Repos via GitHub Agentic Workflows](https://thehackernews.com/2026/07/public-github-issue-could-trick-github.html)
*Noma Security, via The Hacker News — 7 Jul 2026*

Noma Security showed that anyone can open an ordinary-looking public GitHub issue containing hidden instructions that GitHub's Agentic Workflows AI will follow, silently exfiltrating data from private repositories in the same organization — requiring no credentials or access from the attacker, just the ability to file an issue. It matters as another indirect-prompt-injection case where the agent can't distinguish an owner's instructions from attacker text buried in content it was asked to read.

### [Rogue Agent Flaw Could Have Let Attackers Hijack Google Dialogflow CX Chatbots](https://thehackernews.com/2026/07/rogue-agent-flaw-could-have-let.html)
*Varonis, via The Hacker News — ~7 Jul 2026*

Varonis found that all Dialogflow CX agents using Google's "Code Blocks" feature within a GCP project share one Cloud Run execution environment with unrestricted outbound internet access, so an attacker with edit rights on a single agent could compromise every other Code Block-enabled agent in the project, reading live conversations and exfiltrating data outside the VPC-SC perimeter. It matters as a reminder that multi-tenant AI agent platforms can silently share a blast radius across "isolated" agents; Google fully patched it in June 2026 with no evidence of in-the-wild exploitation.

### [Writer AI Flaw ("WriteOut") Could Let Agent Previews Leak Session Tokens Across Tenants](https://thehackernews.com/2026/07/writer-ai-flaw-could-let-agent-previews.html)
*Sand Security, via The Hacker News — 7 Jul 2026*

A one-click flaw in Writer's live-preview feature let an attacker share a public preview link that, when opened by a logged-in victim, forwarded their session cookie into the attacker's sandbox — enabling full account takeover, including access to private chats, connectors, and LLM credentials. It matters as a concrete case of an enterprise generative-AI platform's convenience feature (live preview) breaking tenant isolation; it has since been patched.
